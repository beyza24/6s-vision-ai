# Kurulum (ekip)

1. Daveti kabul et (GitHub e-posta veya repo Invitations).
2. Git + Python 3.11 + GitHub CLI kur.
3. `gh auth login` → GitHub.com, HTTPS, tarayıcı.
4. `gh repo clone beyza24/6s-vision-ai && cd 6s-vision-ai`
5. `python -m venv .venv` → aktive et → `pip install -r requirements.txt`
6. `copy .env.example .env`
7. Cursor’da klasörü aç; Agent modu; `docs/BASLANGIC-PROMPTLARI.md` içinden **kendi** promptunu yapıştır.

Windows: `winget install Git.Git` · `winget install GitHub.cli`
